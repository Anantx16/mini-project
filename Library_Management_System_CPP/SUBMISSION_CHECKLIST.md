# GitHub Submission Checklist

- [ ] Extract the ZIP file.
- [ ] Open a terminal in `Library_Management_System_CPP`.
- [ ] Compile and run using the commands in `README.md`.
- [ ] Test adding a book, registering a member, issuing and returning a book.
- [ ] Check that the data files update after each operation.
- [ ] Initialize Git and push to your own GitHub repository.

Example commands:
```bash
git init
git add .
git commit -m "Add C++ Library Management System mini project"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/Library-Management-System.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username and create the empty repository on GitHub first.
